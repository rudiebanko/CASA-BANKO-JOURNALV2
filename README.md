# CASA BANKO Journal V2

A separate, mobile-first personal trading journal.

## Approved design
- Black and gold CASA BANKO styling
- LOG, OPEN, HISTORY tabs
- Five-question Entry Gate
- Original chart screenshot preview and analysis notes

## Development boundaries
- This repository is independent of `casa-banko-journal` and `casa-banko-checkpoint`.
- Do not copy or commit TradeLocker tokens, passwords, or Supabase service-role keys.
- Do not claim broker synchronization until the authenticated backend is connected and tested.
- Keep user-uploaded charts unmodified.
- Use broker-confirmed balance and P&L once TradeLocker is connected.

Repository initialized. The approved standalone HTML preview is ready for the next commit.
